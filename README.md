# Limit Test

**[limittest.site](https://limittest.site)** — a free, browser-based League of Legends damage
calculator. Configure an attacking and a defending champion — level, ability ranks, items —
order a combo, and get an exact, itemised damage breakdown and a survival verdict.

The calculation runs **entirely in the browser**: no accounts, no server-side state, no
database, no authenticated Riot API access. A scenario is shareable purely through its URL.

## What makes it different

Every damage calculator claims to be accurate and none of them can be checked on it. This one
tells you which numbers it will not stand behind.

## Status

**Working end to end.** All 173 champions produce a result. The site is eight pages: a landing
page, the calculator, how the numbers are checked, a changelog, a report route, about, and the
privacy and cookie policies.

Built and in use:

- **The engine** — sequential simulation, the fixed four-step resistance order, shields, execute
  thresholds, amplification, healing, both survival verdicts. `simulate(scenario, catalogue)`.
- **The data pipeline** — champions, items and runes fetched from the pinned sources, with a
  documented rule for which source wins each field and what happens when they disagree.
- **The ability harvester and its seven gates** — including a round-trip against the wiki's own
  rendering and a cross-check against Riot's shipped arrays.
- **URL sharing** — a complete scenario in the link, versioned, with every published version
  still readable.
- **The interface** — searchable pickers over the full roster, the combo builder, the HP
  burndown, the per-instance breakdown and both resolved stat blocks.

Not built yet: the scheduled patch pipeline (§9), the curated merge of item and rune effects,
the damage-versus-armor and damage-versus-level curves (§11), hosting and CI (§14), and the
advertising containers (§16 — gated on the privacy and cookie policies describing advertising,
see `PLAN.md` §6).

## Development

Requires Node.js. After cloning, run `npm install` once, then:

```bash
npm run dev        # Vite dev server (default http://localhost:5173)
npm run build:coverage  # regenerate the figures the landing page and README quote
npm run typecheck  # tsc --noEmit
npm test           # known-answer test suite (pass/fail counts)
npm run build      # typecheck, then emit the static site to dist/
```

The app is a pure static site — nothing here starts a server or a database.
